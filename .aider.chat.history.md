## Problem

The Convex document endpoints authenticate the caller but do not verify ownership of the target building:

- `src/convex/buildings.ts:getDocuments` returns documents and signed URLs for an arbitrary `buildingId`.
- `src/convex/buildings.ts:addDocument` inserts a document for an arbitrary `buildingId`.

An authenticated user who obtains another building ID could read private document metadata/URLs or attach content to another tenant's building.

## Expected behavior

Every document read or write must load the target building and require `building.userId === authenticatedUserId`. Unauthorized and nonexistent IDs should return the same non-enumerating error.

## Acceptance criteria

- `getDocuments` rejects building IDs not owned by the caller before querying documents or generating URLs.
- `addDocument` rejects building IDs not owned by the caller before inserting.
- Tests cover owner access, cross-user denial, unauthenticated denial, and nonexistent buildings.
- No signed storage URL or document metadata is returned across users.
- Existing owner upload and listing behavior remains functional.

## Severity

High — tenant authorization and private document exposure.
